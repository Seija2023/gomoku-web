# 五子棋网页使用说明

## 1. 启动

最简单的方式是打开 `dist/gomoku.html`。

该文件已经把 HTML、CSS 和 JavaScript 合并到一个文件中，因此无需服务器，也无需安装任何软件。

## 2. 开始对局

1. 黑棋自动先手。
2. 点击棋盘任意空交叉点落子。
3. 白棋随后落子。
4. 双方轮流进行。

页面右上角会显示当前轮到哪一方。

## 3. 获胜条件

任意一方在以下任一方向形成至少五枚连续同色棋子，即立即获胜：

- 横向
- 纵向
- 左上到右下
- 右上到左下

当前版本采用基础五子棋规则，不包含专业竞技五子棋中的禁手规则。

## 4. 悔棋

点击“悔棋”按钮：

- 撤销最近一步
- 当前行动方自动恢复为被撤销棋子的玩家

可以连续悔棋。

## 5. 重新开始

点击“重新开始”会立即清空棋盘并恢复黑棋先手。

## 6. 对局统计

右侧面板显示：

- 黑棋数量
- 白棋数量
- 总手数

最后一步棋会带有红色小标记，方便观察。

## 7. 手机使用

网页采用响应式布局。手机浏览器打开后，棋盘和操作面板会自动调整为纵向布局。

## 8. 修改源代码

### 改标题

编辑 `index.html` 中的：

```html
<title>五子棋 Gomoku</title>
```

### 改棋盘尺寸

逻辑尺寸定义在 `script.js`：

```js
const SIZE = 15;
```

当前 CSS 棋盘网格是按 15×15 设计；如修改 SIZE，还需同步调整样式。

### 增加 AI

建议新增：

```js
function aiMove() {
  // AI 落子策略
}
```

并在玩家落子后调用。

## 9. GitHub Pages 部署思路

仓库建立后，将 `index.html`、`style.css`、`script.js` 放在仓库根目录，即可进一步配置 GitHub Pages 作为在线网页。

GitHub Pages 是否可直接启用取决于仓库和账号设置。
