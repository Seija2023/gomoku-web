# 五子棋网页使用说明

## AI 难度与棋风

难度决定搜索强度：简单 / 普通 / 困难。

棋风人格是独立维度：

- 均衡型：进攻与防守接近平衡
- 进攻型：更重视己方连续棋形
- 防守型：更重视封堵
- 冒险型：更偏向高收益进攻

## Ghost Line 幽灵变化线

PC：把鼠标悬停在可落子的空点上，棋盘会用半透明棋子显示“当前手 → 对手可能回应 → 后续建议”。

手机和平板：长按空点约 0.36 秒进入预览，手指不松开可以拖到其他交叉点重新分析；松手后预览消失且不会落子。正常短按仍然直接落子。

## 候选手 A/B/C

“智能 AI”区域会显示前三个候选位置，并比较：

- 进攻价值
- 防守价值
- 对手可能回应
- 后续建议

手机端使用横向滑动卡片，避免三栏内容被压缩。

## 复盘优势曲线

复盘新增“棋形优势指数”曲线，正值表示黑方棋形更主动，负值表示白方更主动。

该数值是启发式棋形评分，不是胜率。PC 可鼠标定位，手机可手指拖动曲线跳转手数。

## 分享与挑战

复盘中可以：

- 分享整局：生成带棋谱的 URL
- 挑战此局面：生成从当前手数开始的挑战 URL

链接中直接包含压缩棋谱，不需要账号、服务器或数据库。

## 间隔复习

训练中心会记录每道历史残局题的练习状态。

答错后题目会较快再次到期；连续答对后复习间隔逐步拉长。页面显示“今日复习 / 待加强 / 已掌握”。

## 个人开局库

系统按历史棋局前几手自动分组，显示常用开局、使用次数、黑胜/白胜/平局和平均结束手数。

## 复盘与自动播放

保留开局、上一步、下一步、终局、自动播放、关键手过滤和 What-if 分支推演。

自动播放不会调用页面自动滚动，因此可以一直把棋盘保留在视野中。
