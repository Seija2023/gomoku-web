# 五子棋网页使用说明

## 1. 启动

在线版：

```text
https://seija2023.github.io/gomoku-web/
```

离线版可直接打开：

```text
dist/gomoku.html
```

单文件版无需服务器，也无需安装任何软件。

## 2. 游戏模式

页面提供两种模式：

### 双人对战

1. 黑棋先手。
2. 两名玩家在同一设备轮流点击棋盘交叉点。
3. 页面会自动切换当前行动方。

### 人机对战

1. 玩家固定执黑棋并先手。
2. 电脑固定执白棋。
3. 玩家落子后，电脑会短暂“思考”并自动落子。
4. AI 会优先尝试获胜、阻止玩家直接五连，再根据当前棋形选择较优位置。

切换模式会自动开始一盘新棋。

## 3. 获胜条件

任意一方在以下任一方向形成至少五枚连续同色棋子，即立即获胜：

- 横向
- 纵向
- 左上到右下
- 右上到左下

当前版本采用基础自由五子棋规则，不包含专业竞技五子棋中的禁手规则。

## 4. 悔棋

### 双人模式

点击“悔棋”撤销最近一步，并将行动方恢复到被撤销的玩家。

### 人机模式

在人机已经完成落子后点击“悔棋”，通常会同时撤销电脑和玩家最近的一手，使玩家重新思考这一轮。

如果电脑还在“思考中”，点击悔棋会取消待执行的电脑落子并撤销玩家刚刚的一手。

## 5. 音效

点击“音效：开/关”可切换声音。

音效完全由浏览器 Web Audio API 合成，不会加载外部音频文件。浏览器通常要求用户先点击页面后才能播放声音，这是浏览器的正常安全机制。

## 6. 重新开始

点击“重新开始”会立即清空棋盘，并恢复黑棋先手。当前选择的双人/人机模式不会改变。

## 7. 对局统计

右侧或移动端下方的面板会显示：

- 黑棋/玩家棋子数量
- 白棋/电脑棋子数量
- 总手数

最后一步棋会带有红色小标记，方便观察。

## 8. 手机使用

网页采用响应式布局。手机浏览器打开后，棋盘和操作面板自动纵向排列。

棋盘交互点采用透明按钮覆盖交叉点，因此不会再出现浏览器默认按钮背景遮住棋盘的问题。

## 9. 修改源代码

### 页面结构

编辑：

```text
index.html
```

### 样式和移动端布局

编辑：

```text
style.css
```

### 游戏逻辑、AI、音效

编辑：

```text
script.js
```

AI 核心函数包括：

```js
chooseAiMove()
evaluateMove()
patternScore()
```

## 10. GitHub Pages 更新

仓库当前从 `main` 分支根目录发布 GitHub Pages。

只要更新后的 `index.html`、`style.css`、`script.js` 提交到 `main`，GitHub Pages 会自动重新部署。原在线网址保持不变。
