# 使用说明

本文适用于 **Gomoku Web v2.8.1**。

在线版：

```text
https://seija2023.github.io/gomoku-web/
```

## 工作区

主界面分为四个工作区：

- **对局**：PVP / AI、悔棋、重开、历史与规则。
- **分析**：Candidate A/B/C、Ghost Line、Heatmap、AI 解释和 Search Inspector。
- **训练**：今日自适应训练、错题强化、近期弱点与玩家画像。
- **实验室**：Position Editor、Variation Tree 和个人开局库。

PC 使用顶部导航；手机使用固定底部导航。进入复盘、训练、摆局或变化树等特殊模式时，界面会自动切换到对应工作区并暂时锁定冲突入口。

## 对局

### 模式

- 双人本地对战
- 本地 AI 对战

AI 难度：

- 简单
- 普通
- 困难

AI 棋风：

- 均衡
- 进攻
- 防守
- 冒险

未完成的普通对局和自定义局面会保存在浏览器本地，刷新后可恢复。

## AI 分析

### Candidate A/B/C

分析工作区展示当前局面的主要候选，包括攻击 / 防守价值和后续建议。

### Ghost Line 2.0

- PC：悬停空点可预览临时变化线。
- 手机：长按空点进入预览。
- 候选卡可锁定变化线，松开指针后仍保留。
- 变化线最长可显示约 7 ply。

### Heatmap

可显示综合、黑棋或白棋视角的局部棋形价值。

### Search Inspector

默认折叠在“高级搜索详情”中，可查看：

- 实际搜索深度
- 节点数
- 搜索耗时
- 缓存命中
- 战术节点
- Alpha-Beta cutoffs
- 每层推荐变化

“推荐稳定度”表示多个已完成搜索深度中最终推荐手保持一致的比例，不代表胜率。

## Position Editor

实验室中的“自由摆局”支持：

- 摆黑棋 / 白棋
- 擦除
- 指定下一手
- 清空 / 恢复原局
- 对任意非终局局面启用 AI 分析
- 从当前局面开始 PVP 或 AI

### Counterfactual Analysis

打开“比较下一手”后，选择一个空点作为“你的尝试”。系统会比较：

- 你的选择
- AI 推荐
- 即时棋形
- 对手回应
- 后续建议

结果是本地启发式 / 搜索比较，不是精确胜率。

## Variation Tree

可从当前对局或复盘局面进入。

支持：

- 多分支保存
- 手动走分支
- AI 扩展 A/B/C
- 节点命名
- 收藏
- 删除子树
- 返回父节点 / 根节点
- 自动本地保存
- 恢复上次变化树

退出 Variation Tree 不会修改原对局或原复盘。

## 复盘

支持：

- 开局 / 上一步 / 下一步 / 终局
- 自动播放
- 关键手过滤
- 优势曲线
- 从当前位置进入 Variation Tree
- 分享整局
- 分享当前局面挑战

自动播放不会主动改变页面滚动位置。

## Adaptive Training

历史人机对局会用于本地 Mistake Mining。

可能识别：

- 错过直接胜
- 漏防强制威胁
- 战术机会漏算
- 防守优先级不足
- 棋形效率损失

训练题区分：

- **最佳**
- **可接受次优**
- **错误**

系统会结合错误频率、答题结果、题目严重度和复习到期时间安排自适应训练。

个人错题可以直接重练，完成题目后还可进入 Variation Tree 深挖原局面。

## 数据与隐私

核心棋局、设置、训练进度和 Variation Tree 均保存在浏览器本地 localStorage。

项目核心功能不需要：

- 云端 AI API
- API Key
- 账号登录
- 后端数据库

清除浏览器站点数据会同时删除这些本地记录。

## Standalone

开发者可执行：

```bash
npm run build
```

生成：

```text
dist/gomoku.html
```

Standalone 内嵌 CSS、主程序和 Blob Worker，可单文件运行。

`dist/` 是构建产物，不提交到 Git；CI 会为通过验证的构建上传 artifact。
