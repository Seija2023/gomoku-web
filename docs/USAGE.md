# 五子棋网页使用说明

## 1. 启动

在线版：

```text
https://seija2023.github.io/gomoku-web/
```

离线单文件版：

```text
dist/gomoku.html
```

## 2. 对战模式

双人模式由两名玩家在同一设备轮流落子。

人机模式中玩家固定执黑先手，电脑执白。电脑会优先完成直接五连、封堵玩家的直接五连，再根据棋形评分选择位置。

## 3. 终局

对局结束后棋盘不会被全屏弹窗遮住。最终局面会保留，获胜的连续棋子会高亮。

终局结果卡提供：

- 悔棋继续
- 开始复盘
- 再来一局
- 收起结果

即使收起结果，也可以通过右侧“悔棋”继续对局。

## 4. 复盘

复盘支持：

- 跳到开局
- 上一步 / 下一步
- 跳到终局
- 自动播放
- 点击棋谱中的任意一步直接跳转

复盘期间棋盘不能误落子，退出复盘后回到原对局状态。

## 5. 棋谱与分析

棋盘显示 A-O 列坐标和 1-15 行坐标。棋谱使用类似 `H8` 的记法。

基础分析会识别部分明显棋形节点，例如活三、四连威胁、活四和最终五连。该分析是规则与启发式判断，不等同于专业五子棋求解器的唯一最佳手判断。

## 6. 历史与自动恢复

浏览器会保存最近 20 局已结束对局，可在“历史对局”中直接打开复盘。

未结束棋局会自动保存。刷新页面或稍后再次打开时，会自动恢复上次未完成的对局。

## 7. 悔棋

双人模式撤销最近一步。

人机模式会尽量回到玩家可再次落子的状态：通常撤销“电脑 + 玩家”一整轮；若玩家刚刚获胜，则只撤销玩家致胜的最后一步。

## 8. 手机端

手机端自动纵向排列。棋盘交互点保持透明，不会出现浏览器默认按钮背景遮住棋盘的问题。

## 9. 开发入口

- 规则：`js/core/rules.js`
- AI：`js/ai/evaluator.js`
- 对局状态：`js/game/game.js`
- 棋谱：`js/game/history.js`
- 对局分析：`js/analysis/analyzer.js`
- 本地保存：`js/storage/storage.js`
- UI：`js/ui/`
- 主控制流程：`js/main.js`

详细模块关系见 `docs/ARCHITECTURE.md`。
