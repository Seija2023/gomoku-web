# 五子棋网页使用说明

v2.3.1 是性能与架构优化版本，主要界面和操作方式与 v2.3.0 保持一致。

## AI 难度与棋风

难度：简单 / 普通 / 困难。

棋风人格：均衡型 / 进攻型 / 防守型 / 冒险型。

## Ghost Line 幽灵变化线

PC：鼠标悬停可落子的空点，预览“当前手 → 对手可能回应 → 后续建议”。

手机和平板：长按空点约 0.36 秒进入预览，按住拖动可以切换位置；松手后预览消失且不会落子。正常短按仍然直接落子。

## 候选与热力图

智能 AI 区域继续提供候选 A/B/C、进攻/防守价值、对手回应、后续建议和三种热力图视角。

v2.3.1 会缓存同一局面的分析结果，因此切换状态或重复查看时不再重复完成相同计算。

## 复盘

保留：

- 开局 / 上一步 / 下一步 / 终局
- 自动播放
- 关键手过滤
- What-if 分支
- 棋形优势曲线
- 分享整局
- 挑战当前局面

自动播放不会主动滚动页面。

## 训练和历史

保留残局训练、间隔复习、玩家画像、个人开局库和最近 20 局历史。

旧版 localStorage 数据继续兼容；v2.3.1 加入 schema migration，为未来版本的数据结构升级提供兼容路径。

## 离线运行

核心功能继续不依赖后端或云端 AI API。构建后的单文件版本仍可离线运行。
