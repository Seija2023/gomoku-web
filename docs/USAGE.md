# 五子棋网页使用说明

## 1. 启动

在线版：

```text
https://seija2023.github.io/gomoku-web/
```

离线单文件版：

```text
dist/gomoku.html
```

## 2. 游戏模式

### 双人对战

黑棋先手，两名玩家在同一设备轮流点击棋盘交叉点。

### 人机对战

玩家固定执黑棋并先手，电脑执白棋。玩家落子后电脑会短暂显示“思考中…”，随后自动落子。AI 会优先完成自己的五连，其次阻挡玩家的直接五连，再根据棋形评分选择位置。

切换模式会自动开始新棋局。

## 3. 获胜条件

横向、纵向、左上到右下、右上到左下任一方向连续形成至少五枚同色棋子即获胜。

当前版本采用自由五子棋规则，不包含禁手。

## 4. 悔棋

双人模式撤销最近一步，并恢复被撤销一方行动。

人机模式在电脑已落子后通常同时撤销玩家与电脑最近一手；如果电脑仍在思考，则取消待执行的 AI 落子并撤销玩家刚下的一手。

## 5. 音效

“音效：开/关”控制浏览器 Web Audio API 合成的落子、胜利和平局提示音。设置会在浏览器允许时保存到本地。

## 6. 重新开始

“重新开始”清空当前棋盘，但保持当前双人/人机模式。

## 7. 手机端

手机端会自动改为纵向布局。棋盘交互点使用透明按钮覆盖交叉点，因此不会出现浏览器默认白色按钮遮挡棋盘的旧问题。

## 8. 开发者入口

- 页面结构：`index.html`
- 基础与布局样式：`css/`
- 规则：`js/core/rules.js`
- AI：`js/ai/evaluator.js`
- 对局状态与悔棋：`js/game/game.js`
- 音效：`js/audio/audio.js`
- 棋盘和面板渲染：`js/ui/`
- 应用流程：`js/main.js`

详细模块关系见 `docs/ARCHITECTURE.md`。
