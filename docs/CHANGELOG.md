# Changelog

## v2.1.0

### 终局与复盘

- 移除遮挡棋盘的强制终局弹窗，改为可收起的非阻塞结果卡。
- 终局后允许悔棋并继续对局。
- 高亮真正构成胜利的连续棋子。
- 新增完整复盘：开局、上一步、下一步、终局、自动播放。
- 新增棋谱列表，支持点击任意手跳转。
- 新增 A-O / 1-15 棋盘坐标。
- 新增基础棋形分析，识别活三、四连、活四和最终五连等节点。

### 持久化

- 保存最近 20 局已结束对局，并支持从历史记录直接复盘。
- 未完成棋局自动保存，重新打开页面后自动恢复。

### 测试

- 新增胜利线提取、终局悔棋、恢复快照、复盘棋盘、棋谱坐标、分析和本地存储测试。

## v2.0.0

- 将单体脚本和样式拆分为规则、AI、状态、音效、UI 和 CSS 模块。
- 新增自动测试、单文件构建、GitHub Actions CI 和架构文档。
- 保持双人、人机、音效、悔棋、统计和移动端布局功能。
- 修复移动端棋盘白色按钮遮挡与终局延迟弹窗竞态问题。

## v1.1.0

- 修复移动端棋盘白色按钮遮挡。
- 新增人机对战、启发式 AI、音效和星位。

## v1.0.0

- 初始 15×15 双人五子棋版本。
