# Changelog

## v2.0.0

### 工程结构

- 将单体 `script.js` 拆分为配置、规则、AI、对局状态、音效、UI 和应用控制模块。
- 将单体 `style.css` 拆分为基础、布局、棋盘、组件和响应式样式。
- 新增 `package.json`、自动测试与单文件构建脚本。
- 新增 GitHub Actions CI，在 push / pull request 时自动运行测试和构建。
- 新增架构文档 `docs/ARCHITECTURE.md`。

### 兼容与修复

- 保持双人、人机、AI、音效、悔棋、统计、移动端布局等 v1 功能不变。
- 保留透明棋盘交互层，防止移动端白色按钮遮挡问题回归。
- 修复胜利后快速悔棋/重开时，延迟弹窗仍可能再次弹出的定时器竞态问题。

## v1.1.0

- 修复移动端棋盘白色按钮遮挡。
- 新增人机对战、启发式 AI、音效和星位。

## v1.0.0

- 初始 15×15 双人五子棋版本。
