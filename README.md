# 五子棋 Gomoku Web

一个无需后端即可运行的 15×15 五子棋网页小游戏。支持本地 AI、复盘、局势分析、分支推演和训练，核心功能无需 API。

在线版：

```text
https://seija2023.github.io/gomoku-web/
```

当前工程版本：**v2.3.0（智能对弈实验室）**。

## v2.3.0 重点

- Ghost Line 幽灵变化线
  - PC：鼠标悬停空点
  - 手机：长按约 0.36 秒进入预览，拖动切换点位，松手不落子
- AI 棋风人格：均衡型 / 进攻型 / 防守型 / 冒险型
- 候选手 A/B/C 对比：进攻、防守、对手回应、后续建议
- 复盘棋形优势曲线，可点击或拖动定位手数
- 棋局分享与“挑战此局面”链接，棋谱直接编码进 URL，无服务器
- 残局训练加入间隔复习：今日复习、待加强、已掌握
- 个人开局库：自动统计常用前几手、使用次数和结果
- 历史记录界面显示已保存的最近 20 局

## 既有能力

- 双人本地对战与人机对战
- 简单 / 普通 / 困难三档 AI
- 可解释 AI、威胁热力图
- 关键手与明显失误检测
- 复盘时间轴、“只看关键手”、What-if 分支复盘
- 历史残局训练与玩家棋风统计
- 终局悔棋、胜利线高亮、自动恢复
- 自动复盘不会主动滚动页面
- 桌面与手机响应式布局
- 单文件离线构建，无第三方运行时依赖

## 开发检查

```bash
npm test
npm run build
```

所有 AI、Ghost Line、分享编码、优势曲线、开局库和训练调度均在浏览器本地运行。

## 规则说明

当前采用基础自由五子棋规则，不实现 Renju 的三三、四四、长连等禁手。
