# 五子棋 Gomoku Web

一个无需安装、无需后端、可直接在浏览器运行的 15×15 五子棋网页小游戏。

在线版（GitHub Pages）：

```text
https://seija2023.github.io/gomoku-web/
```

## 功能

- 15×15 棋盘，修复移动端棋盘被按钮默认背景遮挡的问题
- 双人本地对战
- 人机对战：玩家执黑先手，电脑执白
- AI 会优先完成五连、拦截对手五连，并根据棋形与中心位置选择落点
- 自动检测横向、纵向和两种斜向五连
- 落子音效、胜利音效、平局音效，可随时关闭
- 自动显示胜负结果
- 标记最后一步落子
- 悔棋（人机模式下会尽量回退一整轮“玩家 + 电脑”）
- 重新开始
- 对局手数统计
- 响应式布局，兼容电脑与手机浏览器
- 纯 HTML / CSS / JavaScript，无第三方依赖

## 快速开始

### 在线游玩

直接打开 GitHub Pages：

```text
https://seija2023.github.io/gomoku-web/
```

### 离线运行成品

打开：

```text
dist/gomoku.html
```

该文件已把 HTML、CSS、JavaScript 合并为一个文件，双击即可运行。

### 运行源代码版本

保持以下文件在同一目录：

```text
index.html
style.css
script.js
```

然后双击 `index.html`。

## 人机模式说明

人机模式下：

- 玩家固定执黑棋并先手。
- 电脑固定执白棋。
- AI 首先检查自己是否能立即获胜。
- 若玩家下一手可能五连，AI 会优先封堵。
- 其他情况下，AI 会对候选位置进行进攻、防守与中心位置评分。

这是轻量级启发式 AI，不依赖服务器，也不会联网计算。

## 音效说明

音效使用浏览器原生 Web Audio API 合成，不需要额外的 MP3/WAV 文件。

- 黑棋、白棋落子使用不同音高。
- 胜利时播放三音提示。
- 平局时播放结束提示。
- “音效：开/关”状态会在浏览器允许的情况下保存到本地。

## 技术说明

棋盘使用 15×15 二维数组保存状态：

- `0`：空位
- `1`：黑棋 / 玩家
- `2`：白棋 / 电脑

每次落子后，从当前棋子出发检查四组方向：

1. 水平 `(0, 1)`
2. 垂直 `(1, 0)`
3. 主对角线 `(1, 1)`
4. 副对角线 `(1, -1)`

正反两个方向累计同色连续棋子数量，达到 5 即判定获胜。

## 规则说明

当前项目采用基础自由五子棋规则，不实现 Renju 专业规则中的三三、四四、长连等禁手。
