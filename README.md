# 五子棋 Gomoku Web

一个无需安装、无需后端、可直接在浏览器运行的 15×15 五子棋网页小游戏。

## 功能

- 15×15 标准棋盘
- 黑棋先手，黑白双方轮流落子
- 自动检测横向、纵向、两种斜向五连
- 自动显示胜负结果
- 标记最后一步落子
- 悔棋
- 重新开始
- 对局手数统计
- 响应式布局，兼容电脑与手机浏览器
- 纯 HTML / CSS / JavaScript，无第三方依赖

## 快速开始

### 方法一：直接运行成品

打开：

```text
dist/gomoku.html
```

双击即可在浏览器中运行。

### 方法二：运行源代码版本

保持以下文件在同一目录：

```text
index.html
style.css
script.js
```

然后双击 `index.html`。

## 技术说明

棋盘使用 15×15 二维数组保存状态：

- `0`：空位
- `1`：黑棋
- `2`：白棋

每次落子后，从当前棋子出发检查四组方向：

1. 水平 `(0, 1)`
2. 垂直 `(1, 0)`
3. 主对角线 `(1, 1)`
4. 副对角线 `(1, -1)`

正反两个方向累计同色连续棋子数量，达到 5 即判定获胜。
